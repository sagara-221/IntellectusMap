画面の入口と、最初の探索

詳細ユーザーマニュアル / 01　ログインから地図作成まで

探索テーマを地図にする

テーマを狭めるほど、見たい知識の範囲を伝えやすくなります。

確認はノードごと

同じ地図の中でも、理解度・問題・準備状況は項目ごとに異なります。

上部メニュー用途
探索新しいテーマを始める、または現在の探索を続ける。
深堀マップ一覧作成した地図を探し、開く。タイトル等の編集や削除もここから。
繋がりMAP一覧系統を選び、その中の地図と未探索候補の関係を見る。
知識ノード一覧地図を横断して、自分の項目を探して詳細を見る。

開始手順

公開環境ではGoogleログインを行い、「探索」でテーマと任意のメモを入力します。「このテーマを探索する」を押すと探索受付が開き、初期地図の作成が進みます。環境によってログイン方法が異なる場合があります。

入力の例

テーマ：「CADの選び方」。メモ：「機械設計の初心者。2Dと3Dの使い分け、製図、データ互換を知りたい。価格比較は今回は対象外」。範囲や目的を書くと、会話の出発点を共有できます。

表示するのはログイン中のユーザーの地図です。別アカウントで開くと一覧が異なります。この資料は2026年10月13日、develop_v2 / 2026-10-13更新版の実装を対象としています。

探索受付で知識を増やす

詳細ユーザーマニュアル / 02　会話の使い方

受付係に話す

経験・説明できること・疑問を自由に入力して送信します。

記録係が整理する

発言から情報を取り出して、既存項目への対応や追加先を調べます。

  1. 受付の候補文を押すと、入力欄に話し始めの文が入ります。自分の内容を追記して送信します。
  2. 返答を読み、具体例・理由・迷っている点を追加します。単語の列挙より「何ができ、どこで迷うか」が評価の手がかりになります。
  3. 地図への反映状況を確認します。会話から複数の項目が生まれたり、既存項目の理解度が更新されたりします。
  4. 作られた枝は、祖先の表示も含めて自動で開きます。後から準備できた子項目も順に表示対象になります。

送るとよい内容

「知っている」だけでなく、「この式をこう使った」「このケースでは判断できない」と説明してください。会話評価は発言内容を根拠にするため、説明が具体的なほど何を確認できたかを記録しやすくなります。

会話を切り替える

「会話履歴」で過去の会話を表示できます。「新しい会話」は同じ地図の中で会話を区切る機能で、地図・理解度・過去の会話を消しません。過去の会話を見ているときは「現在の会話に戻る」から送信へ戻ります。

チャット由来の項目に付く暫定20%は、理解を確認した得点ではありません。通常の初期分解の項目すべてに一律で付くわけではありません。

調査手帳で理解を確かめる

詳細ユーザーマニュアル / 03　自己評価・問題・展開

ノードをクリックして開く

右上の拡大ボタンで手帳の領域を広げられます。長い内容は内部をスクロールします。

問題・回答は必要な項目だけ

問題確認を始めた対象ノードで表示します。他のノードの問題を共通表示する機能ではありません。

ページできること
調査依頼自己評価、問題での確認、下位項目の展開など、次の操作を選ぶ。
問題・回答問題を解き、回答を送信してフィードバックを読む。必要な状態のときだけ表示。
調査記録項目の詳細、回答や会話からの根拠、理解度の情報を確認する。

自己評価して先へ進む

「自信アリ」90%、「そこそこ」55%、「ちょっと」20%を選ぶと、保存後に下位項目を自動展開します。根拠の確かさは自己申告として低く扱われます。開始ノードは下位項目の集計を見る場所で、同じ自己評価操作の対象ではありません。

問題で確かめる

「問題で理解度を確認する」を選び、問題が表示されたら選択肢を選んで回答を送信します。評価と説明を読み、画面に出る次の操作へ進みます。追加確認が利用できる項目では、過去の根拠を含めた再評価も行えます。

問題を飛ばす

「問題を飛ばして下位項目を展開」は、問題生成が終わる前でも使える操作です。準備済みの子があれば表示へ進み、未準備なら分解を待ちます。問題を飛ばしただけで採点したことにはなりません。

ページのタブと左右ボタンで切り替えます。受付を開くときは手帳を閉じてください。ボタンが処理中の間は、保存中・展開中などの表示を確認します。

深堀MAPを読み、操作する

詳細ユーザーマニュアル / 04　地図の視覚表現

未確認

点線リングと石碑。未評価と0%は区別します。

理解度：高

80%以上。中は40%以上80%未満、低は40%未満。

旗は根拠の確かさ

70%未満または不明なら白旗。70%以上なら色付き。

宝箱は準備状況

開いていても理解済みとは限りません。

操作効果
ホイール / ＋・－地図を拡大・縮小する。
ノードをドラッグ力方向グラフの位置を動かす。離すと周囲との力関係で調整される。
配置を整える配置を計算し直す。落ち着くまで操作が待機になる場合がある。
知識を検索目的の項目を見つけやすくする。
理解度チェック外した段階を薄く小さくする。データは削除しない。
理解度エリア / 動きを抑える背景の理解度表現、アニメーション量を調整する。

等高線と道路

等高線は開始地点からのつながりの距離を基に描きます。理解度や難易度の高さではありません。深堀MAPで両端の理解度が80%以上のエッジは、道のような線になります。

「分解候補なし」はAIの末端判定。「親の結果で出題省略」は子を直接採点していない状態です。どちらも「理解済み」と同義ではありません。

繋がりMAPで探索範囲を広げる

詳細ユーザーマニュアル / 05　地図をまたぐ関連テーマ

深堀MAP

ひとつのテーマを下位の知識項目に分けて調べます。

繋がりMAP

地図や未探索の候補を結び、別のテーマへ進む入口にします。

  1. 上部の「繋がりMAP一覧」を開き、見たい系統を選びます。すべての系統をひとつのグラフに混ぜて表示する方式ではありません。
  2. 地図上の候補、または地図内パネルの「未探索の候補」から項目を選びます。
  3. 展開元・関係・理由を確認します。エッジの関係表現も、つながりの意味を読む手がかりです。
  4. 詳しく調べたい候補なら「このテーマで深掘りを始める」を押します。候補を起点とする深掘りへ進みます。
  5. 関連候補を増やしたい場合は「さらに広げる」を使います。処理中は進捗と調査隊の表示を確認します。

配置と移動

繋がりMAPはRPGの海図風です。砂浜と草地の島がノードで、探索済みは桟橋付き、未探索は小さな島、開始地点は大きな島です。選択中の島は明るい縁取りで示します。繋がりMAPも力方向グラフです。ノードをドラッグして配置を変え、拡大縮小して関係を追えます。等高線はここでも接続距離を基にする背景表現で、能力を採点するものではありません。

地図や項目を後から探す

「深堀マップ一覧」や「知識ノード一覧」の検索・並べ替えを使います。地図一覧ではタイトル等を編集できます。項目名を見つけたら詳細を確認し、該当する探索へ戻ります。

未探索の候補は、まだ十分に調べていない行き先です。候補の名前が表示されたことと、その知識を確認済みであることは別です。

保存・削除と、困ったとき

詳細ユーザーマニュアル / 06　日常の確認ポイント

BASE CAMPの×数字

その役割の待機人数。最大数から稼働数を引いた表示です。

警告印

生成失敗。手帳や受付に出る説明と再試行操作を確認してください。

症状確認・操作
開いた宝箱なのに待つ準備済みでも、対象問題の取得・選択状態の切替・保存等が残る場合があります。手帳の進捗を確認。
返答は来たが地図が増えない裏の抽出・配置・分解・評価が続いている可能性があります。反映状況を確認し、失敗時は再試行。
理解度が後から変わる新しい根拠や、子の集計が反映された可能性があります。調査記録で評価元を確認。
問題・回答タブがないそのノードで問題確認を始めていない場合は正常です。調査依頼から確認を開始。
ログインや接続に失敗利用アカウントと通信を確認。再ログイン後も続く場合は、操作・時刻・表示エラーを管理者へ伝える。

保存

処理結果はサーバー側に保存されます。「保存」や「診断記録を保存」は、探索データをJSONファイルとして手元にダウンロードする操作です。この画面には、そのJSONを読み戻す操作はありません。

削除

地図の削除は関連する記録にも影響します。ノード削除は同じ地図の下位項目を含み、別の親と共有されている子にも影響します。確認ダイアログの対象を必ず読みます。ノード削除では会話の原文と他の地図は残ります。

一覧や旗・建物の全パターンは「アイコン早見一覧」「アイコン詳細ガイド」を参照してください。ここでの説明は実装を調査したもので、本番環境の全操作を実行して確認した記録ではありません。
