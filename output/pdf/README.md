## 更新方法

今回の3冊の本文・図・レイアウトは [`scripts/build-user-manuals.mjs`](../../scripts/build-user-manuals.mjs) にあります。既存のアイコン早見一覧HTMLから実装由来の画像を読み込みます。

リポジトリ直下で、フロントエンドの開発依存関係とMicrosoft Edgeが利用できる状態で実行します。

```sh
npm --prefix frontend ci
node scripts/build-user-manuals.mjs
```

実行すると3冊のPDFとHTMLを再生成し、簡易・詳細版を `frontend/public/manuals/` に同期します。画面上部の「ユーザーマニュアル」から閲覧できます。PDFもビルド成果物に含まれるため、本番環境で利用できます。アイコン画像から更新する場合は、先に `node scripts/build-icon-guides.mjs` を実行してください。

ページ領域のはみ出しはスクリプトで確認し、更新後はPDFを画像化して文字・画像・改ページも目視確認してください。

資料はコードを調査した説明であり、本番環境の全機能の動作試験結果ではありません。環境変数で変更可能なモデルや並列数は、ソースの既定値として記載しています。
