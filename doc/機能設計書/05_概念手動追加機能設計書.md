# 05. 概念手動追加 機能設計書

## 1. 機能概要

- AIが自動生成した知識ツリーに対し、ユーザーが学習したい独自の概念ノードを手動で追加する編集機能を提供する。
- ノード追加時は指定の親ノードとの包含エッジ（`contains`）を構築する。

## 2. 入出力

### 概念追加
- **入力**: セッションID (`session_id`), 概念名 (`name`), 説明 (`description`), 親ノードID (`parent_id`)
- **出力**: 作成された新ノードオブジェクト (`ConceptNode`), 作成されたエッジ (`Edge`)

## 3. 処理フロー

### 概念追加フロー
1. `name` の文字数（1〜100文字）をバリデーション。
2. セッションのツリー内に新しい一意な概念ID（`concept_manual_<uuid>`）を発行。
3. `parent_id` が指定されている場合、親ノードの存在を確認し深さ（`depth = parent.depth + 1`）を算出（未指定時はルート直下）。
4. 新ノード（理解度: `unknown`）および親子エッジをツリーに追加。
5. セッションをDBに保存。

## 4. バリデーション

- 同一親ノード直下に同一名称の概念が既に存在する場合は重複エラー。
- 存在しない親ノードIDの指定はエラー。

## 5. エラーハンドリング

| エラーケース | ステータスコード | レスポンス例 | 備考 |
| --- | --- | --- | --- |
| 親ノードが見つからない | 404 | `{"detail": "指定された親ノードが存在しません。"}` | 参照先不在 |
| 概念名が空文字 | 400 | `{"detail": "概念名を入力してください。"}` | 必須不足 |
