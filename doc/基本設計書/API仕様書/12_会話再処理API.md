# 12. 会話再処理 API 詳細仕様

## 1. エンドポイント情報

| 項目 | 内容 |
| --- | --- |
| メソッド | POST |
| URL | /api/sessions/{session_id}/chat/reprocess |
| 概要 | ツリーのノード追加・分解等で概念構造が変化した際、既存の会話履歴を再スキャンして未評価ノードに対する理解エビデンスを再抽出し、ツリーの理解度判定に反映させる |
| 認証 | 任意（Bearer Token） |
| レスポンス形式 | application/json |

## 2. リクエストパラメータ

### 2.1 パスパラメータ

| パラメータ名 | 型 | 必須 | 制約 | 説明 |
| --- | --- | --- | --- | --- |
| `session_id` | string | 必須 | `sess_` prefix | 対象の診断セッションID |

### 2.2 リクエストボディ
なし

## 3. レスポンス仕様

### 3.1 HTTPステータスコード

| ステータスコード | 意味 | 発生条件 |
| --- | --- | --- |
| 200 OK | 要求受付 | バックグラウンド再処理タスクがキューイングされた場合 |
| 404 Not Found | リソース不在 | 指定セッションIDが存在しない場合 |

### 3.2 成功レスポンス例 (200 OK)

```json
{
  "status": "queued",
  "background_status": "queued",
  "pending_nodes_count": 3
}
```
