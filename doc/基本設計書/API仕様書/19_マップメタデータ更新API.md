# 19. マップメタデータ更新 API 詳細仕様

## 1. エンドポイント情報

| 項目 | 内容 |
| --- | --- |
| メソッド | PATCH |
| URL | /api/maps/{map_id} |
| 概要 | 保存された知識マップのタイトルや説明メモなどのメタデータを更新する |
| 認証 | 任意（Bearer Token） |
| レスポンス形式 | application/json |

## 2. リクエストパラメータ

### 2.1 パスパラメータ

| パラメータ名 | 型 | 必須 | 制約 | 説明 |
| --- | --- | --- | --- | --- |
| `map_id` | string | 必須 | `sess_` prefix | 対象の知識マップID（セッションIDと同一） |

### 2.2 リクエストボディ

| フィールド名 | 型 | 必須 | 制約 | 説明 |
| --- | --- | --- | --- | --- |
| `title` | string | 任意 | 1〜300文字 | 更新後のマップタイトル |
| `description` | string | 任意 | 最大5000文字 | 更新後のマップ説明メモ |

## 3. レスポンス仕様

### 3.1 HTTPステータスコード

| ステータスコード | 意味 | 発生条件 |
| --- | --- | --- |
| 200 OK | 更新成功 | メタデータが正常に更新された場合 |
| 404 Not Found | リソース不在 | 指定マップIDが存在しない場合 |

### 3.2 成功レスポンス例 (200 OK)

更新後のマップ詳細オブジェクト（`KnowledgeMap`）が返却される。
