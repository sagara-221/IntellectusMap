# 01. 認証状態取得 API 詳細仕様

## 1. エンドポイント情報

| 項目 | 内容 |
| --- | --- |
| メソッド | GET |
| URL | /api/auth/me |
| 概要 | クライアントが保持するトークンに基づき、現在の認証ユーザーIDおよびゲスト状態を取得する |
| 認証 | 任意（Bearer Token）。トークンなしの場合は `guest_user` として処理 |
| レスポンス形式 | application/json |

## 2. リクエストパラメータ

### 2.1 ヘッダーパラメータ

| パラメータ名 | 型 | 必須 | デフォルト値 | 制約 | 説明 |
| --- | --- | --- | --- | --- | --- |
| `Authorization` | string | 任意 | なし | `Bearer <Firebase ID Token / Test Token>` | 認証トークン。指定がない場合はゲストユーザーとして扱われる |

### 2.2 クエリパラメータ
なし

### 2.3 リクエストボディ
なし

## 3. レスポンス仕様

### 3.1 HTTPステータスコード

| ステータスコード | 意味 | 発生条件 |
| --- | --- | --- |
| 200 OK | 取得成功 | 正常に認証状態情報が取得された場合 |
| 401 Unauthorized | 認証失敗 | トークンのフォーマット不正または有効期限切れ |
| 500 Internal Server Error | サーバーエラー | バックエンド内部エラー |

### 3.2 レスポンスボディ項目一覧

| フィールド名 | 型 | Nullable | 説明 | 具体例 |
| --- | --- | --- | --- | --- |
| `user_id` | string | ✕ | 認証されたユーザーの一意識別子（Google ID Token の sub または `guest_user`） | `"user_google_1029384756"` |
| `is_guest` | boolean | ✕ | ゲストユーザー（Basic認証テストモード含む）であるか否か | `false` |

### 3.3 成功レスポンス例 (200 OK)

```json
{
  "user_id": "108392847291847281928",
  "is_guest": false
}
```

### 3.4 エラーレスポンス例 (401 Unauthorized)

```json
{
  "detail": "認証トークンが無効または期限切れです。"
}
```
