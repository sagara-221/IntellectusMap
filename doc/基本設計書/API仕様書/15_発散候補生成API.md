# 15. 発散候補生成 API 詳細仕様

## 1. エンドポイント情報

| 項目 | 内容 |
| --- | --- |
| メソッド | POST |
| URL | /api/maps/{map_id}/concepts/{concept_id}/divergence |
| 概要 | 指定された概念ノードを起点として、関連・応用・発展する新たな学習テーマの発散候補（派生マップの種）をAI生成する |
| 認証 | 不要（パブリック） |
| リクエスト形式 | application/json |
| レスポンス形式 | application/json |

## 2. リクエストパラメータ

### 2.1 パスパラメータ

| パラメータ名 | 型 | 必須 | 制約 | 説明 |
| --- | --- | --- | --- | --- |
| `map_id` | string | ○ | `sess_` prefix | 起点となる知識マップID |
| `concept_id` | string | ○ | 1文字以上 | 発散の起点とする概念ノードID |

### 2.2 クエリパラメータ / リクエストボディ
なし

## 3. レスポンス仕様

### 3.1 HTTPステータスコード

| ステータスコード | 意味 | 発生条件 |
| --- | --- | --- |
| 200 OK | 生成成功 | 発散候補バッチが正常に生成・保存された |
| 404 Not Found | 未存在 | 指定された `map_id` または `concept_id` が存在しない |
| 503 Service Unavailable | 生成エラー | LLM（`DivergenceAgent`）によるテーマ発散処理のタイムアウトやエラー |

### 3.2 レスポンスボディ項目一覧（DivergenceBatchオブジェクト）

| フィールド名 | 型 | Nullable | 説明 | 具体例 |
| --- | --- | --- | --- | --- |
| `source_map_id` | string | ✕ | 起点元のマップID | `"sess_8f3a91b2c4e5"` |
| `source_concept_id` | string | ✕ | 起点元の概念ノードID | `"c_diff_coeff"` |
| `source_concept_name` | string | ✕ | 起点元の概念名 | `"平均変化率と微分係数"` |
| `candidates` | array of object | ✕ | **生成された発散候補テーマ一覧（1〜15件）**（後述 3.2.1） | `[ ... ]` |

#### 3.2.1 `candidates` の各要素（DivergenceCandidateオブジェクト）の項目一覧
| フィールド名 | 型 | Nullable | 説明 | 具体例 |
| --- | --- | --- | --- | --- |
| `id` | string | ✕ | 発散候補の一意識別子 (`candidate_` prefix) | `"candidate_7f8a9b0c"` |
| `name` | string | ✕ | 提案された派生マップのテーマ名 | `"微分を用いた力学運動方程式"` |
| `category` | string | ✕ | 発散のカテゴリ分類 | `"物理・工学への応用"` |
| `relation` | string | ✕ | 元概念との関係性の説明 | `"瞬間の変化率としての微分が、速度や加速度の定義に直結する"` |
| `reason` | string | ✕ | このテーマを学習することを推奨する理由 | `"抽象的な微分の計算が現実の現象と結びつき、理解が深まるため"` |

## 4. 業務処理ロジック・仕様

1. **ツリー経路の抽出**:
   - 起点ノードからルートまでの先祖パス（例: `["微分法と導関数", "平均変化率と微分係数"]`）を抽出し、LLMプロンプトのコンテキストとして渡す。
2. **既存テーマとの重複防止**:
   - リポジトリに既に存在するマップのタイトル一覧（最大80件）を抽出し、既存マップと重複しない斬新かつ有意義なテーマを発散生成させる。
3. **候補の保存と再利用**:
   - 生成された候補バッチはデータベース（`divergence_candidates` テーブル）に永続化される。後続の「14. 発散マップ作成 API」で `candidate_id` を指定することで、この候補から派生マップを即座に作成できる。
