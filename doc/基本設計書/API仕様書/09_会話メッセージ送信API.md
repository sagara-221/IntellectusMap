# 09. 会話メッセージ送信 API 詳細仕様

## 1. エンドポイント情報

| 項目 | 内容 |
| --- | --- |
| メソッド | POST |
| URL | /api/sessions/{session_id}/chat |
| 概要 | 学習者の自由記述発言を送信し、AI返答をServer-Sent Events (SSE) でストリーミング受信する。同時にバックグラウンドで会話から概念理解のエビデンスを自動抽出し、知識ツリーを更新する |
| 認証 | 任意（Bearer Token） |
| レスポンス形式 | text/event-stream |
| 利用条件 | 手動探索（`manual` / `decomposition_first`）かつ未完了のセッションのみ |

## 2. リクエストパラメータ

### 2.1 パスパラメータ

| パラメータ名 | 型 | 必須 | 制約 | 説明 |
| --- | --- | --- | --- | --- |
| `session_id` | string | 必須 | | 対象の診断セッションID |

### 2.2 リクエストボディ（`ChatRequest`）

| フィールド名 | 型 | 必須 | 制約 | 説明 |
| --- | --- | --- | --- | --- |
| `message_id` | string | 必須 | 1〜100文字、`^[a-zA-Z0-9_-]+$` | 発言ID（再送時の冪等キー） |
| `content` | string | 必須 | 1〜100000文字 | ユーザーの発言テキスト |
| `concept_id` | string | 任意 | 存在するノードID | 注目している概念ノードID |
| `conversation_id` | string | 任意 | 現在の会話IDと一致 | 送信先の会話スレッドID（省略時は現在の会話） |

## 3. レスポンス仕様

### 3.1 HTTPステータスコード

| ステータスコード | 意味 | 発生条件 |
| --- | --- | --- |
| 200 OK | ストリーミング開始 | SSE接続が確立された場合 |
| 404 Not Found | リソース不在 | セッションまたは `concept_id` が存在しない場合 |
| 409 Conflict | 競合 | 返答生成中、または会話が切り替わっている場合 |
| 422 / 400 | 不正リクエスト | 完了済み・対象外モードのセッション、`message_id` の別内容での再利用 |

### 3.2 SSEイベント形式

| イベントタイプ | フィールド | 説明 |
| --- | --- | --- |
| `phase` | `phase` | 処理段階通知（例: `replying`） |
| `delta` | `message_id`, `text` | AI返答テキストの差分 |
| `complete` | `session` | 返答完了および最新のセッション状態 |
| `error` | `message`, `session`(任意) | 生成失敗通知 |

同一 `message_id` で返答済みの場合は、保存済み結果を `complete` で即時返却する。
