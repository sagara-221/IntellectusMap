# 21. 理解度サマリー全体取得 API 詳細仕様

## 1. エンドポイント情報

| 項目 | 内容 |
| --- | --- |
| メソッド | GET |
| URL | /api/understanding-summary |
| 概要 | 全知識マップ系統（Lineage）を横断した理解度サマリーの全体ルート情報を取得する |
| 認証 | 不要（パブリック） |
| レスポンス形式 | application/json |

## 2. リクエストパラメータ

### 2.1 クエリパラメータ / ヘッダー / リクエストボディ
なし

## 3. レスポンス仕様

### 3.1 HTTPステータスコード

| ステータスコード | 意味 | 発生条件 |
| --- | --- | --- |
| 200 OK | 取得成功 | 全系統サマリーデータが正常に返却された |
| 500 Internal Server Error | サーバーエラー | データベース取得処理の障害 |

### 3.2 レスポンスボディ項目一覧（全体サマリーオブジェクト）

| フィールド名 | 型 | Nullable | 説明 | 具体例 |
| --- | --- | --- | --- | --- |
| `title` | string | ✕ | 全体サマリーの固定名称 | `"すべての知識"` |
| `lineages` | array of object | ✕ | **登録されている各知識系統のサマリー一覧**（後述 3.2.1） | `[ ... ]` |

#### 3.2.1 `lineages` の各要素（LineageSummaryオブジェクト）の項目一覧
| フィールド名 | 型 | Nullable | 説明 | 具体例 |
| --- | --- | --- | --- | --- |
| `lineage_id` | string | ✕ | マップ系統グループの一意識別子 | `"lineage_1a2b3c4d"` |
| `root_map_id` | string | ✕ | 系統の起点・親となるルートマップID | `"sess_8f3a91b2c4e5"` |
| `title` | string | ✕ | 系統の代表タイトル（ルートマップのテーマ名） | `"微分法と導関数"` |
| `map_ids` | array of string | ✕ | 当該系統に属するすべてのマップIDの配列 | `["sess_8f3a91b2c4e5", "sess_999999999999"]` |
| `map_count` | integer | ✕ | 当該系統に含まれるマップの総数 | `2` |

### 3.3 成功レスポンス例 (200 OK)

```json
{
  "title": "すべての知識",
  "lineages": [
    {
      "lineage_id": "lineage_1a2b3c4d",
      "root_map_id": "sess_8f3a91b2c4e5",
      "title": "微分法と導関数",
      "map_ids": [
        "sess_8f3a91b2c4e5",
        "sess_999999999999"
      ],
      "map_count": 2
    },
    {
      "lineage_id": "lineage_5e6f7a8b",
      "root_map_id": "sess_222222222222",
      "title": "Python非同期処理",
      "map_ids": [
        "sess_222222222222"
      ],
      "map_count": 1
    }
  ]
}
```

### 3.4 エラーレスポンス例 (500 Internal Server Error)

```json
{
  "detail": "データベース接続エラーが発生しました。"
}
```

## 4. 業務処理ロジック・仕様

1. **系統単位の集約**:
   - `knowledge_maps` テーブルおよび系統マッピング情報から、ルートマップを起点とする系統グループ一覧を抽出し、所属するマップ数（`map_count`）を集計して返却する。
2. **階層ナビゲーション**:
   - フロントエンドの理解度ダッシュボードにおける最上位階層（系統選択ビュー）のデータソースとして使用される。
