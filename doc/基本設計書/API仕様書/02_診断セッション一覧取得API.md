# 02. 診断セッション一覧取得 API 詳細仕様

## 1. エンドポイント情報

| 項目 | 内容 |
| --- | --- |
| メソッド | GET |
| URL | /api/sessions |
| 概要 | ユーザーが所有する診断セッションの概要一覧を取得する |
| 認証 | 任意（Bearer Token）。トークンなしの場合は `guest_user` として処理 |
| レスポンス形式 | application/json |

## 2. リクエストパラメータ

### 2.1 ヘッダーパラメータ

| パラメータ名 | 型 | 必須 | デフォルト値 | 制約 | 説明 |
| --- | --- | --- | --- | --- | --- |
| `Authorization` | string | 任意 | なし | `Bearer <Firebase ID Token>` | 認証トークン。指定がない場合はゲストユーザーとして扱われる |

### 2.2 クエリパラメータ
なし

### 2.3 リクエストボディ
なし

## 3. レスポンス仕様

### 3.1 HTTPステータスコード

| ステータスコード | 意味 | 発生条件 |
| --- | --- | --- |
| 200 OK | 取得成功 | 正常にセッション一覧が取得された場合（0件の場合も空配列を返却） |
| 500 Internal Server Error | サーバーエラー | データベース接続障害等の内部エラー |

### 3.2 レスポンスボディ項目一覧（配列の各要素）

返却データは、以下のセッション概要オブジェクトの配列（`Array<SessionSummary>`）である。

| フィールド名 | 型 | Nullable | 説明 | 具体例 |
| --- | --- | --- | --- | --- |
| `session_id` | string | ✕ | 診断セッションの一意識別子 (`sess_` prefix) | `"sess_9b4a1c2d3e4f5a6b"` |
| `theme` | string | ✕ | 診断の主題テーマ | `"微分法と導関数"` |
| `complete` | boolean | ✕ | 診断が完了状態であるか否か | `false` |
| `questions_answered` | integer | ✕ | これまでに学習者が回答した問題の総数 | `3` |
| `created_at` | string | ✕ | セッション作成日時（ISO 8601 UTC形式） | `"2026-10-04T10:15:30.123456+00:00"` |
| `updated_at` | string | ○ | セッション最終更新日時（ISO 8601 UTC形式、未更新時はnull） | `"2026-10-04T10:25:00.654321+00:00"` |

### 3.3 成功レスポンス例 (200 OK)

```json
[
  {
    "session_id": "sess_9b4a1c2d3e4f5a6b",
    "theme": "微分法と導関数",
    "complete": false,
    "questions_answered": 3,
    "created_at": "2026-10-04T10:15:30.123456+00:00",
    "updated_at": "2026-10-04T10:25:00.654321+00:00"
  },
  {
    "session_id": "sess_1a2b3c4d5e6f7a8b",
    "theme": "Python非同期処理とasyncio",
    "complete": true,
    "questions_answered": 7,
    "created_at": "2026-10-03T18:00:00.000000+00:00",
    "updated_at": "2026-10-03T18:22:15.000000+00:00"
  }
]
```

### 3.4 エラーレスポンス例 (500 Internal Server Error)

```json
{
  "detail": "データベース接続に失敗しました。"
}
```

## 4. 業務処理ロジック・仕様

1. **ユーザー絞り込み**:
   - `Authorization` ヘッダーから抽出された `user_id` に紐づくセッション一覧を抽出する。
   - トークンが未指定の場合、デフォルトで `guest_user` のセッションを返却する。
   - `test_user` または `guest_user` の場合は該当ユーザーのセッションが返却対象となる。
2. **ソート順**:
   - セッションの更新日時（または作成日時）の降順（新しい順）で配列を整列して返却する。
3. **データ軽量化**:
   - 一覧表示用として、ツリー構造や問題本文などの大きなペイロードは含めず、セッションID・テーマ・進捗数などのメタデータのみを高速に返却する。
