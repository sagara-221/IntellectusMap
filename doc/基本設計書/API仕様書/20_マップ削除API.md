# 20. マップ削除 API 詳細仕様

## 1. エンドポイント情報

| 項目 | 内容 |
| --- | --- |
| メソッド | DELETE |
| URL | /api/maps/{map_id} |
| 概要 | 指定された知識マップ、および関連する診断セッションデータ・進行中の非同期タスクを完全に削除する |
| 認証 | 不要（パブリック） |
| レスポンス形式 | application/json |

## 2. リクエストパラメータ

### 2.1 パスパラメータ

| パラメータ名 | 型 | 必須 | 制約 | 説明 |
| --- | --- | --- | --- | --- |
| `map_id` | string | ○ | `sess_` prefix | 削除対象とする知識マップID |

### 2.2 クエリパラメータ / リクエストボディ
なし

## 3. レスポンス仕様

### 3.1 HTTPステータスコード

| ステータスコード | 意味 | 発生条件 |
| --- | --- | --- |
| 200 OK | 削除成功 | マップおよびセッションデータが正常に削除された |
| 404 Not Found | 未存在 | 指定された `map_id` のマップが存在しない |
| 500 Internal Server Error | サーバーエラー | データベース削除処理中の内部エラー |

### 3.2 レスポンスボディ項目一覧

| フィールド名 | 型 | Nullable | 説明 | 具体例 |
| --- | --- | --- | --- | --- |
| `deleted_map_id` | string | ✕ | 削除完了した知識マップID | `"sess_8f3a91b2c4e5"` |

### 3.3 成功レスポンス例 (200 OK)

```json
{
  "deleted_map_id": "sess_8f3a91b2c4e5"
}
```

### 3.4 エラーレスポンス例 (404 Not Found)

```json
{
  "detail": "指定されたマップが見つかりません。"
}
```

## 4. 業務処理ロジック・仕様

1. **非同期タスクの中断**:
   - 該当マップに関連して実行中（またはスケジュール中）の先行生成タスク（prefetch）、初期ツリー構築タスク、およびマップ間マッチングタスクを安全にキャンセル（中止）する。
2. **データベース抹消**:
   - `knowledge_maps`, `sessions`, `knowledge_map_relations`, `map_concept_relations`, `prefetched_decompositions` 等の関連テーブルから、当該 `map_id` に属するレコードをカスケード削除する。
3. **系統への影響**:
   - 系統内に他の派生マップが存在する場合は系統グループ自体は維持され、マップ一覧から削除マップのみが除外される。
